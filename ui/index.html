Setup
1
Open Claude Code in the AI RPG project directory
2
Make sure Laragon is running (PHP at localhost)
3
Type play rpg in Claude Code to start the Game Master loop
4
Type your actions below and press Enter to send
5
If the GM stops responding, type play rpg again in Claude Code
GM Commands
/new-game
Start fresh — opens world & character wizard
/save-game [name]
Save current progress to a named slot
/load-game [path]
Restore a save with a narrative recap
/save-world [name]
Save world/lore/factions as a reusable preset
/list-saves
Show all available save slots
/rewind
Restore last auto-snapshot (every 5 turns)
/force-event [desc]
Inject a world event immediately
/spawn [name] [role]
Add an NPC to the current scene
/set-stat [stat] [value]
Override a character stat directly
/set-mental [value]
Set mental state 0–100 (100 triggers takeover)
/simulate [scenario]
Test a scenario without writing to files
/reveal [lore-id]
Reveal hidden lore (e.g. lore_005)
/faction-event [faction] [event]
Trigger a faction-level change
Tips
Enter to send · Shift+Enter for a new line
Click a GM message while it's typing to skip to the end instantly
Toggle Voice in the header to hear GM narration read aloud
The GM loop is self-sustaining — it reschedules itself every 8 seconds
Auto-snapshots every 5 turns — /rewind to restore the last one
Saves live in AI RPG\saves\ · Presets in AI RPG\world-presets\
